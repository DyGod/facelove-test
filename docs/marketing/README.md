# Marketing docs

Notes on conversion work for the store. Written for whoever runs marketing, design or the theme, so nobody has to read the code to know what changed and why.

- [cro-changes.md](cro-changes.md) is the log of changes we shipped to pages. Newest first.
- [test-hypotheses.md](test-hypotheses.md) records why we made each change: what we believed, and what would prove us wrong.

## How to add an entry

When you change something on a page to improve sales, add a line to the change log the same day. Say what page, what changed, and why. If the change is a guess, write it up as a hypothesis first and link to it.

Keep it short and plain. A teammate should understand an entry in under a minute.
